# codex桥接workbuddy v4.0.0

将本人已登录的 WorkBuddy 账号接入 Codex / CC Switch，提供账号、余额、模型倍率和实际扣分管理。

## 本次修复

- 修复错误横幅一直保留的问题：可手动关闭，错误提示 12 秒自动收起，成功提示 4.5 秒收起。
- 切换页面、切换区域、重新操作和取消登录时清理旧提示。
- 避免旧操作或旧计时器覆盖新操作的提示。
- 区分上游超时、网络、证书及本机桥接连接错误，不再把所有错误都建议为重新登录。
- 保留国内 / 国际账号、扫码接入、积分柱状图和扣费明细。

## 下载选择

| 附件 | 用途 |
| --- | --- |
| `codex-workbuddy-bridge-v4.0.0-setup.exe` | Windows 安装程序：解压到当前用户目录并创建桌面图标，不设置开机自启 |
| `codex-workbuddy-bridge-v4.0.0-portable.zip` | 便携运行包：解压后打开 `CodexWorkBuddyBridge.exe` |
| `codex-workbuddy-bridge-v4.0.0-source.zip` | 完整源码、中文文档、演示截图与构建脚本 |

运行仍需本机 Node.js 22+、Chrome 和 Windows 自带 .NET Framework。安装程序不内置 Node.js 或 Chrome，不自动读取账号、不修改 CC Switch。

## 更新

先停止旧版，再使用新版。需要保留旧账号时，在旧版停止后将其 `data` 目录完整复制到新版目录，Windows 上需使用同一系统用户。不要在两个版本之间同时共享正在写入的数据目录。

本项目使用 WorkBuddy 的非公开接口，上游变更可能需要后续适配。请仅使用自己的账号。
